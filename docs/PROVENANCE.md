# Policy-bundle provenance

The research and coder bundles adapt mechanisms described in Cursor's
MIT-licensed `pstack` plugin at `cursor/plugins@bdf7aa3` (plugin 0.14.3): named
playbooks, self-contained briefs, evidence-first investigation, isolated
workers, exact-SHA verification, adversarial review, and durable handoff.

The text in `profiles/` was written for nswarm's Hermes/control-plane contract;
substantial pstack text was not copied. If future work copies substantial text,
the source copyright and MIT notice must be added beside that material before
merge.
