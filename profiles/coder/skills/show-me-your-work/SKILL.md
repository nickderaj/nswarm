name: show-me-your-work
description: Emit an exact-SHA candidate report with commands, artifacts, risks, and limitations.
policy-version: v1
---

Report repository, base SHA, head SHA, changed paths, acceptance mapping, exact
commands and exit results, behavioural evidence, artifact digests, remaining
risks, and deviations. Validate the report schema. Self-report never upgrades a
candidate to verified.
