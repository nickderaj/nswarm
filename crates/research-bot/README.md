# research-bot

The Step 5 profile, skills and machine-validated evidence contract are present,
but this executable remains deliberately fail-closed. D23 invalidated the
selected Hermes HTTP conversation route, and D24 remains unevaluated, so there
is no model-backed `ask` surface or live research session yet.

Research repository access is read-only. Its only writable capability is the
schema-validated evidence ledger owned by `agent-control`; the profile cannot
edit or push a repository, mutate tickets or chat, merge, or deploy.
